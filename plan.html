Folder zip 修補計劃

zip 解得開。以下按傷害排，一次改 server.js／index.html／test.js。唔開新檔，唔加依賴。

做

1. CRC 改用 zlib

而家 crc32 係 JS 逐 byte 計。資料夾有片，CPU 會 Sem 住。

刪 CRC_TABLE 同手寫 crc32。頂部 const { crc32 } = require('zlib')。API 一樣，逐 chunk 傳上一輪嘅值。

Node 20.15+ 先有。家用機應該得。舊過呢個先至要加返 JS fallback。

2. Skip symlink／junction

collectZip 用 isDirectory()。Windows junction 當目錄，指去上一層就無限遞迴，download 斷。亦可以 pack 到 share root 外面。

e.isSymbolicLink() 就 continue。檔同資料夾捷徑一齊唔跟。

/up 造唔到 junction，要 host 自己放先中。一行就堵。

3. 取消下載要停 stream

對方撳取消，drain listener 同 createReadStream 未必清，promise 可以掛住。

每個檔：res.on('close', () => rs.destroy())。destroy 之後 error／end 會走現有 cleanup。

4. DOS time clamp

mtime 早過 1980，writeUInt16LE throw，zip 打到一半爛。

dosTime 把年限制喺 1980–2107。一行數學，唔使分支表。

5. zip 失敗要出聲

zipDir(...).catch 而家只 destroy()。加 console.error，唔好吞。

6. 測多兩樣

而家只 check PK magic 同檔名。加：nested 解壓後內容；symlink 唔入 zip。繼續無 framework，callback 接喺 test.js。

7. SVG 只留一份

index.html 個 icon 複製咗兩次。抽 const DL_SVG = '…'，bar 同列表共用。

唔做

zip64、壓縮、進度條、content-length。檔大過 4GB 或者一個資料夾超過 65535 個 entry 先至要。家用未到。

順序

  1. zlib CRC（刪碼，順便快）
  2. skip symlink（安全同遞迴一齊解）
  3. close 停 stream
  4. dosTime clamp
  5. console.error
  6. test
  7. SVG const

1–5 都喺 server.js，一次改完跑 node test.js。6、7 跟住。
